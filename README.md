# yumapai-web

YuMapAI'nin **derlenmiş web sürümü** (kaynak kod değil). Kaynak: `gkhnocak-dot/yumapai` (gizli).
cPanel Git Version Control bu depoyu çeker; `.cpanel.yml` dosyaları `public_html/` (yumapai.com) altına kopyalar; ilk dağıtımda eski ana sayfa `_eski_site_20261115/` klasörüne yedeklenir ve `tanitim/` adresine taşınır.
Elle değiştirmeyin: her sürüm `yumapai` deposundan derlenip buraya konur.
