YuMapAI web — first-party mirror of the Flutter web engine fallback fonts (D-119W).
Roboto: Apache License 2.0. Noto fonts (Noto Sans, Noto Sans Symbols / Symbols 2 / Math / Arabic / Hebrew /
Georgian / Armenian / Thai / Devanagari, Noto Color Emoji, and every other Noto family in an `all` build):
SIL Open Font License 1.1. Files are copies of fonts.gstatic.com/s/<family>/<version>/<file>, served from this origin
so no visitor request reaches Google. Mirror mode: core — 28 of 725 engine fallback files.
16.11.2026: the folders were first mirrored for an older engine (notocoloremoji v32, notosans v37, ...); Flutter 3.50 asks for
newer paths (v39, v42, ...) and every request was 404, so category emojis drew as empty boxes. The folders were renamed to the
versions the engine asks for (same file names, same glyph ranges). test/web/ikon_kontrol.py (madde 5) checks the match after every build.
20.11.2026: Japanese is not in the engine mirror; Noto Sans JP (OFL 1.1) subset ships as assets/fonts/NotoSansJP-*.otf with its license record
assets/fonts/NotoSansJP-OFL.txt and is loaded with FontLoader only when Japanese is selected. Arabic and Cyrillic come from the mirror above.
